# 🌐 Proyecto-Web
![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)

Práctica de **introducción al desarrollo web** (HTML y CSS): un sitio multipágina con navegación, horario, información y contacto.

## 📄 Páginas
| Página | Contenido |
|---|---|
| `Inicio.html` | Página principal |
| `Informacion.html` | Sección informativa |
| `Horario.html` | Horario |
| `Contacto.html` | Formulario de contacto |

## 🚀 Cómo verlo
```
git clone https://github.com/RoDeluxe/Proyecto-Web.git
cd Proyecto-Web
# abre Inicio.html con doble clic
```

## 🗂 Estructura
```
Inicio.html · Informacion.html · Horario.html · Contacto.html
css/           hojas de estilo
assets/        recursos del sitio
```
